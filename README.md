# CampusConnect

## College Events and Campus Activity Platform

CampusConnect is a simple web-based application designed to help college students discover upcoming events, student clubs, campus announcements, and important campus locations from a single platform.

The project is developed using only HTML, CSS, and JavaScript and does not require a database or backend server.

---

## Project Overview

College students often receive information about events and activities through different communication channels. This can make it difficult to keep track of technical events, cultural programs, sports activities, workshops, clubs, and announcements.

CampusConnect provides a centralized interface where students can:

- Discover college events
- Search for events
- Filter events by category
- View event details
- Register for events
- Explore student clubs
- View campus announcements
- Explore important campus locations
- Switch between light and dark themes
- Access a simple student login interface

---

## Features

### 1. Home Page

The home section provides an overview of the platform and displays upcoming campus events.

### 2. Event Discovery

Students can browse different college events such as:

- Technical Events
- Cultural Events
- Sports Events
- Workshops

### 3. Event Search

Users can search for events using the search box.

### 4. Event Filtering

Events can be filtered based on categories:

- All
- Technical
- Cultural
- Sports
- Workshops

### 5. Event Details

Users can click the "View Details" button to see additional information about an event.

### 6. Event Registration

The application provides a demo registration function for students.

### 7. Student Clubs

Students can explore different clubs such as:

- Tech Club
- Arts Club
- Sports Club
- Music Club

### 8. Campus Announcements

Important college announcements are displayed in a separate section.

### 9. Campus Locations

The application provides information about important campus venues such as:

- Main Auditorium
- Innovation Laboratory
- College Sports Ground

### 10. Dark Mode

Users can switch between light and dark themes.

### 11. Student Login

A simple demo login interface is included.

### 12. Responsive Design

The website works on:

- Desktop
- Laptop
- Tablet
- Mobile devices
